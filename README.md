# Library Management System

A university software engineering project developed for the **Software Engineering** course at the University of Slavonski Brod, Croatia.

The project focuses on requirements analysis, system design, UML modeling, and user interface prototyping for a library management information system.

## Project Overview

The Library Management System is a proposed web-based information system designed to simplify library operations, including book management, member records, borrowing, and returns.

The project demonstrates the software engineering process, from defining functional and non-functional requirements to creating UML diagrams and user interface prototypes.

## Key Features (System Design)

- User authentication and role-based access control
- Book searching and availability tracking
- Book borrowing and returns
- Library member management
- Book inventory management
- Loan records and tracking
- User account administration

## User Roles

### Library Member

- Search and browse available books
- View personal borrowing records
- Borrow available books

### Librarian

- Record book loans and returns
- Access book and member information
- Track borrowing activities

### Administrator

- Manage user accounts
- Add, update, and remove books
- Maintain library records
